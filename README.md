# 🚀 Estudos de Vue 3 com TypeScript

Este repositório contém meus códigos de estudo e exercícios práticos desenvolvidos ao acompanhar a playlist de Vue 3 do canal do **Tiago Matos** no YouTube.

## 📌 Sobre o Projeto

Embora o curso original seja ministrado utilizando **JavaScript**, optei por fazer o projeto aplicando **TypeScript** do zero. O objetivo foi desafiar meu aprendizado, reforçando a tipagem estática, interfaces e as boas práticas que o TypeScript traz para o desenvolvimento com Vue 3.

## 🛠️ Tecnologias Utilizadas

- **Vue 3** (Composition API / Options API)
- **TypeScript**
- **HTML5 & CSS3**

## 📚 Conteúdo Praticado

- [x] Estrutura e ciclo de vida de componentes Vue
- [x] Data Binding (`v-bind`, `v-model`)
- [x] Renderização condicional (`v-if`, `v-else`) e de listas (`v-for`)
- [x] Manipulação de eventos (`v-on` / `@`)
- [x] Tipagem de dados e objetos com TypeScript (`interfaces` e `types`)
